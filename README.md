## 📖 项目简介

两个纯前端圣诞树特效页面，可直接在浏览器中打开欣赏。

## ✨ 效果

| 文件 | 效果 |
|------|------|
| `christmas_tree.html` | 传统 CSS 圣诞树 |
| `particle_christmas_tree.html` | Canvas 粒子动画圣诞树 |

## 🚀 快速开始

直接用浏览器打开 `.html` 文件即可。

```bash
# 或启动本地服务器
npx serve .
```
